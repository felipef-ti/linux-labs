# Linux Labs 🐧

Este repositório reúne meus estudos e laboratórios práticos de Linux.

O objetivo é documentar minha evolução na administração de sistemas Linux por meio de exemplos reais, comandos, scripts e boas práticas.

---

## Conteúdo

- Estrutura de diretórios
- Comandos básicos
- Gerenciamento de usuários
- Permissões
- Processos
- Serviços (systemctl)
- Pacotes (APT)
- Redes
- Bash Script
- Logs
- Firewall (UFW)

---

## Ambiente utilizado

- Ubuntu Server
- VirtualBox
- Git
- GitHub

---

## Objetivo

Construir conhecimento sólido em administração Linux voltado para Infraestrutura e Cloud Computing.
